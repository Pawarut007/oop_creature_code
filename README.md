# Creature Battle Project (OOP + Git Branching Practice)

This project is designed to help me learn Object-Oriented Programming
in Python, especially inheritance, while practicing Git concepts.

## Learning Objectives

### Python / OOP
- Understand and implement classes.
- Use inheritance to extend behaviors.
- Override methods such as attack().
- Practice writing test code.

### Git / Version Control
- Create and switch branches.
- Merge branches into main.
- Resolve merge conflicts.
- View commit history.

## Project Structure

- creature_simulation.py - Contains the Creature class and subclasses.
- README.md - Project documentation.

## How to Run and Test

1. Open the project folder in VS Code.
2. Open the terminal.
3. Run the program:

   python creature_simulation.py
